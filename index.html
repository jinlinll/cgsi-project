Skill internalization

The guide is gone.
Why cite it?

A common way to internalize a skill is to generate demonstration trajectories with the skill in context using the model itself, and then fine-tune the same model on them with the skill removed. It changes the training input but keeps the supervision target, so the model learns to reproduce what it wrote with the skill.

At test time, the trained agent can still say it consulted that guide. Our method, CGSI, corrects the training signal so the agent can use what it learned without crediting a guide it never received on this task.

From example to explanation

How a reference survives after the guide is removed.

Learn with a guide

During training, an agent gets a written guide called a skill. Its successful answers become examples for teaching it to act on its own.

Remove the guide

A common recipe removes the guide from each training input but keeps the answer. Phrases like “according to the skills” remain in the text the agent learns to produce.

Correct the example

Our method, CGSI, detects sentences that cite the missing guide. It skips those words when computing the training loss (Mask), or rewrites the sentence (Rewrite).

How often does skill removal leave unsupported references in successful demonstrations?

When the skill is removed, 18–75% of successful demonstrations contain at least one reference that loses its support. On ARC-AGI-1 with the 9B model, this happens in 1,721 of 2,281 successful trajectories.

Can CGSI reduce CoMi while preserving task success?

Across six full-parameter settings, CGSI (Mask) reduces CoMi by 72.5–94.6% relative to SFT (skill dropped). On WebShop with Qwen3.5-4B, CoMi falls from 46.0% to 3.4%, while task success goes from 39.2% to 41.6%.

Does it matter which sentences are masked?

On WebShop, random masking and CGSI mask the same number of sentences. The 4B agent still cites missing guidance in 49.4% of test trajectories after random masking, compared with 3.4% after detector-selected masking.

How much CoMi remains after RL without the skill?

After 60 skill-free GRPO updates on ALFWorld and WebShop, task success improves from every initialization. Models initialized from SFT (skill dropped) still show CoMi in 8.4–35.2% of test trajectories, compared with 0.4–5.2% for the corrected initializations.

Does asking the teacher not to mention the skill reduce CoMi in its demonstrations?

On 1,000 ALFWorld tasks, adding that instruction raises removal-induced CoMi from 38.9% to 51.9%. Some responses cite the prohibition itself:

“The system instructions say not to mention the skill or its contents in thinking.”
